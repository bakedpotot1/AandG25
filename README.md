# Wedding Information Website

A responsive wedding information website built as a personal project using HTML, CSS and JavaScript.

The website was created to give wedding guests a single place to find important information about the day, including the schedule, location and RSVP options.

## Features

- Responsive design optimised for different mobile screen sizes
- Navigation links to different sections of the page
- Image gallery
- "Read More" functionality for the couple's story
- Wedding schedule
- Embedded Google Maps location
- RSVP links via WhatsApp and email

## Technologies Used

- HTML
- CSS
- JavaScript

- Structuring a webpage using HTML

- Using media queries to support different screen sizes
- Adding interactivity with JavaScript

- Embedding external content such as Google Maps
- Publishing and maintaining a project using GitHub

## Project Background

This was a real-world personal project built for a friend's wedding. The original website included personal contact details and event-specific information. Sensitive contact details have been anonymised in this public version.

The project was designed primarily with mobile users in mind, as guests accessed the website through a QR code included on their wedding invitations.

## Possible Future Improvements

If I were to revisit the project, I would consider:

- Improving the desktop layout and responsiveness
- Refactoring the HTML and CSS for cleaner structure
- Improving accessibility, including image alt text
- Adding a dedicated RSVP form rather than external contact links
- Further optimising the site for different screen sizes
- Improving code organisation and maintainability
